# SophisticatedBackpacks (sp fork)

Fork of the Fabric port of Sophisticated Backpacks for Minecraft 1.20.1, licensed under GPL-3.0.
It adds native Accessories support. See `changelog.md` for the modifications.

Upstream: https://github.com/Salandora/SophisticatedBackpacks (original mod by P3pp3rF1y).
Issues for this fork: https://github.com/DrArzter/SophisticatedBackpacks/issues

## Development

The build needs Java 17 and no secrets. Sophisticated Core comes from Modrinth Maven.

    ./gradlew build

The jars are in `build/libs`.
